2. Customer Referral System

Every customer reward profile should have a unique referral code.

Referral codes should be simple and shareable, for example:
- CANDY-AUSTIN123
- CCZ-AB12CD
- or another clean format.

Customer referral workflow:
- Existing customer shares referral code.
- New customer enters referral code during checkout/order request.
- Referral code gets attached to the order and the new customer profile.
- The referred customer gets a configurable bonus, such as points or discount.
- The referring customer gets a configurable bonus after the referred customer’s first completed order.

Admin settings should control:
- Enable/disable customer referrals
- Referrer bonus points
- New customer bonus points
- Whether referral bonus is awarded immediately or after completed order
- One referral bonus per new customer
- Referral expiration, optional
- Minimum order amount for referral reward
- Whether referrals can stack with other promotions

Admin referral dashboard should show:
- Total referral orders
- Top referring customers
- Referral code used
- New customer name/phone
- Referrer name/phone
- Pending referral rewards
- Completed referral rewards
- Flagged/suspicious referrals

Fraud/abuse prevention:
- Do not let a customer refer themselves using the same phone number.
- Only allow one “referred by” code per customer.
- Prevent repeated referral bonuses for the same referred customer.
- Allow admin to manually approve, reject, or flag referrals if needed.

3. Staff Referral System

Add a separate staff referral system that is different from customer referrals.

Each staff member or promoter should be able to have a unique staff referral code.

Staff referral examples:
- STAFF-MARY
- STAFF-AUSTIN
- CCZ-MARY10
- CCZ-EVENT01

Staff referrals should be used to track who brought in the customer/order.

Staff referral workflow:
- Customer enters a staff referral code at checkout/order request.
- Order is tagged with the staff referral code.
- Staff referral gets credit for that order.
- Admin can see how many orders each staff member brought in.

Admin should be able to:
- Create staff referral codes
- Assign code to staff/person
- Enable/disable code
- Set code type: staff, promoter, event, booth, influencer, flyer, Facebook ad, manual
- Add notes
- View total orders from each staff code
- View total sales from each staff code
- View pending/completed credit
- Mark staff referral credit as paid/unpaid if payout tracking is used

Staff referral dashboard should include:
- Staff code
- Staff name
- Number of orders
- Total order value
- Completed order value
- Pending order value
- Last order date
- Paid/unpaid tracking
- Simple leaderboard

Important:
Customer referral rewards and staff referral credit are separate systems.
A customer order may have:
- One customer referral code
- One staff/source referral code
They should not overwrite each other.
