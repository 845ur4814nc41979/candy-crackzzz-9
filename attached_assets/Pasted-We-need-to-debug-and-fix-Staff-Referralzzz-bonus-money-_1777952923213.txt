Step 3 — Define correct bonus calculation rules

Implement these exact rules:

A. Signup bonus:
If:
- staff referral program enabled
- allow signup bonus enabled
- customer signed up through a valid active staff code
- no signup bonus was already issued for that referred customer/staff code

Then:
- create a staff bonus record
- bonus type = signup
- amount = fixed signup bonus
- status = pending if approval required, otherwise approved
- attach staffId/staffCode/referredCustomerId
- show it in Bonus Queue if pending or approved
- include it in Pending/Approved/Lifetime totals

B. First completed order bonus:
If:
- staff referral program enabled
- allow first completed order bonus enabled
- referred customer has a valid staff referral code
- order is completed or treated as completed by this app’s order flow
- order total is at or above minimum order total
- no first-order staff bonus was already issued for that referred customer/order

Then calculate:
- fixed first-order bonus
plus
- first-order percentage bonus if percentage is greater than 0

Apply max bonus per order cap if set.

Create a staff bonus record:
- type = first_order
- status = pending if approval required, otherwise approved
- attach orderId/orderTotal/staffId/staffCode/referredCustomerId
- show in Bonus Queue
- include in totals

C. Every completed order bonus:
If:
- allow every completed order bonus enabled
- customer came from staff referral
- order qualifies
- bonus for this specific order has not already been issued

Then calculate:
- every-order percentage of order total
- apply minimum order and max bonus cap
- create pending/approved bonus record

D. Duplicate protection:
Never award the same staff bonus twice for:
- same staffId
- same referredCustomerId
- same orderId
- same bonus type

But do not let duplicate protection block the first valid bonus.
